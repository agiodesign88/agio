# AGIO_srm

아지오의 취향으로 선정한 공간을 탐색하는 모바일 우선 웹 앱입니다.

## 현재 기능
- 인트로, 공간 목록 및 상세 화면, 지도, 저장, 설정
- 공간 11개와 편집 사진 76장
- OpenFreeMap / MapLibre 기반 무채색 지도와 컬러 핀
- 카카오 주소 검색 및 도보·대중교통·자동차 길찾기
- 브라우저 IndexedDB에 저장하는 개인 방문 사진과 저장 지도
- JPG, PNG, WebP, HEIC 사진 입력
- 로컬 관리자 페이지: /lab.html

## 로컬 실행
Node.js 22 이상이 필요합니다. 별도 npm 의존성 설치는 없습니다.

1. .env.example을 .env.local로 복사하고 카카오 키를 입력합니다.
2. npm run dev 또는 node --env-file-if-exists=.env.local server.mjs
3. http://127.0.0.1:4317/ 접속

검증: node --test tests/*.test.mjs

## 데이터와 보안
공간 정보는 data/places.json, 편집 사진은 public/uploads에 있습니다.
방문 사진은 각 브라우저에만 저장되며 서버 업로드·계정 동기화·공개 기능은 아직 없습니다.
실제 키, 개인 방문 기록, 원본 이미지와 백업은 저장소에 포함하지 않습니다.

## Vercel 연결 전 준비
이 커밋은 현재 로컬 작업물의 보관본입니다. Vercel 배포용 변환은 아직 적용하지 않았습니다.
현재 서버는 localhost만 허용하며 JSON 파일과 업로드 폴더에 직접 기록합니다.
Vercel용 API 진입점, 외부 데이터 저장소 또는 조회 전용 카탈로그,
관리자 인증/쓰기 API 차단, 서버 환경변수 설정이 필요합니다.
일반 사용자의 사진 업로드는 별도의 저장소 및 중단 복구 구현이 필요합니다.

## 라이선스
지도 및 폰트 등 포함된 외부 라이브러리의 라이선스는 public/vendor에 있습니다.
공간 사진과 브랜드 콘텐츠는 AGIO DESIGN의 콘텐츠로, 별도의 오픈소스 사용 허가를 제공하지 않습니다.
